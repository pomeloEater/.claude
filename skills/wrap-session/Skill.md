# Wrap Session

세션을 깔끔하게 마무리한다. 아래 순서를 반드시 지킨다.

## 실행 순서

### 1단계 — 작업 요약 출력

이번 세션에서 한 일을 아래 형식으로 정리한다:

```
## 이번 세션 요약

### ✅ 완료
- [완료된 기능/수정 항목]

### 🚧 진행 중 / 남은 작업
- [다음 세션에서 이어할 항목]

### ⚠️ 주의사항 / 메모
- [다음 세션에서 알아야 할 것, 있으면 기재]
```

### 2단계 — CLAUDE.md 업데이트

현재 프로젝트의 CLAUDE.md를 찾아 읽고:
- "완료된 기능 ✅" 섹션에 이번에 완료한 항목 추가
- "진행 중 / 남은 작업 🚧" 섹션을 현재 상태로 갱신
- 새로 알게 된 주의사항이 있으면 "알려진 주의사항" 섹션에 추가

CLAUDE.md가 없으면 사용자에게 알리고 넘어간다.

### 3단계 — git 상태 확인 및 commit 제안

`git status`와 `git diff --stat`를 실행하고:
- 변경된 파일 목록을 보여준다
- 커밋 메시지 초안을 제안한다 (실제 커밋은 사용자 확인 후)

커밋 메시지 형식:
```
[완료 기능 한 줄 요약]

- 세부 변경사항 1
- 세부 변경사항 2
```

## 인자 처리

- `/wrap-session` — 위 순서 전체 실행
- `/wrap-session [메모]` — $ARGUMENTS 내용을 "주의사항/메모"에 포함

## 주의

- 1단계 요약 → 2단계 CLAUDE.md 업데이트 → 3단계 git 순서를 반드시 지킨다
- git commit은 사용자 확인 없이 실행하지 않는다
- CLAUDE.md 업데이트는 기존 내용을 지우지 않고 갱신만 한다
