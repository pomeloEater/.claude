# Start Session

새 세션을 빠르게 궤도에 올린다. 아래 순서로 실행한다.

## 실행 순서

### 1단계 — CLAUDE.md 읽기

현재 작업 디렉토리에서 CLAUDE.md를 찾아 읽는다.
없으면: "CLAUDE.md가 없습니다. 프로젝트 루트 경로를 알려주세요." 라고 말하고 멈춘다.

### 2단계 — 현재 상태 요약 출력

CLAUDE.md 기반으로 아래 형식으로 짧게 출력:

```
## 프로젝트 현황

**프로젝트:** [프로젝트명]
**마지막 완료:** [최근 완료 항목]
**남은 작업:**
- [항목 1]
- [항목 2]
```

길게 설명하지 않는다. 핵심만.

### 3단계 — 타이머 알림

아래 문구를 출력한다:

```
⏱ 세션 타이머 3시간을 설정하세요. (3시간 초과 시 /wrap-session)
```

### 4단계 — 오늘 작업 확인

인자($ARGUMENTS)가 있으면: 해당 작업부터 바로 시작한다.
인자가 없으면: "어떤 작업부터 시작할까요?" 라고 한 줄만 묻는다.

## 인자 처리

- `/start-session` — CLAUDE.md 읽고 작업 물어보기
- `/start-session [작업명]` — CLAUDE.md 읽고 해당 작업 바로 시작

예:
- `/start-session` → 현황 요약 후 "어떤 작업부터 시작할까요?"
- `/start-session 인수처리 화면 구현` → 현황 요약 후 인수처리 화면 관련 파일 바로 탐색 시작

## 주의

- 2단계 요약은 짧게. CLAUDE.md 전체를 그대로 출력하지 않는다.
- 불필요한 인사말("안녕하세요!", "오늘도 화이팅!" 등) 없이 바로 요약으로 시작한다.
- 작업이 결정되면 관련 파일을 먼저 읽고 행동으로 들어간다.
