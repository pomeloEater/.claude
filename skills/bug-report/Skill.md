# Bug Report

사용자가 버그를 신고하려 한다. 아래 3단계 형식으로 버그를 파악하고 즉시 수정을 시작한다.

## 동작 방식

**`/bug-report` 뒤에 설명이 있는 경우:**
사용자가 제공한 내용을 아래 형식으로 해석하고, 부족한 정보가 있으면 한 번에 모아서 질문한다. 충분한 정보가 있으면 바로 관련 파일을 읽고 수정을 시작한다.

**`/bug-report` 만 입력한 경우:**
아래 체크리스트를 보여주고 사용자가 채워넣도록 안내한다.

## 버그 파악 3단계

```
1. 화면/파일   → 어떤 파일 또는 화면에서 발생했는가?
2. 동작        → 어떤 행동을 했을 때 발생하는가?
3. 결과        → 실제 결과는? 예상 결과는?
```

## 인자가 없을 때 출력할 체크리스트

```
🐛 버그 신고 — 아래 내용을 채워서 다시 입력해줘:

파일/화면:
동작:
실제 결과:
예상 결과:
조건 (선택):
```

## 정보가 충분할 때

3단계 정보가 확인되면 즉시:
1. 해당 파일을 Read로 읽기
2. 원인 파악
3. 수정 시작

중간에 "파악했습니다" 같은 불필요한 메시지 없이 바로 행동으로 들어간다.

## 사용 예시

```
/bug-report $ARGUMENTS
```

예:
- `/bug-report` → 체크리스트 안내
- `/bug-report detail-dialog.jsp에서 저장 버튼 클릭 시 403 에러 남. 저장이 되어야 함.` → 바로 파일 읽고 수정 시작
